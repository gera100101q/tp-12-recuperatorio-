## 📌 Concepto de la Mascota
El personaje elegido es **Steve (Minecraft)** adaptado e integrado con la identidad del **IPET 249**:
* **Atributos Informáticos:** Equipado con auriculares gaming, anteojos de programador y una estación de trabajo virtual.
* **Identidad Institucional:** Vestido con la camiseta oficial del colegio con los colores institucionales (**Bordó y Amarillo**) y el escudo del IPET 249 presente en pantalla.

---

## 🎮 Manual de Uso e Interacción
Para mantener con vida a Steve Copérnico, el usuario debe gestionar 3 barras de estado que se consumen progresivamente con el tiempo:

1. **Carga de Batería / Energía (Tecla `C`):** Al presionar la tecla **C**, Steve toma un *Café de Sistemas* para recargar energías.
2. **Nivel de Código / Ánimo (Tecla `P`):** Al presionar la tecla **P**, Steve escribe código en Python para mantener su nivel de programación.
3. **Limpia de Bugs / Salud (Tecla `B`):** Al presionar la tecla **B**, Steve realiza una rutina de depuración (*debugging*) para eliminar bugs del software.

### Expresiones de la Mascota:
* **Estado Normal / Feliz:** Ojos azules claros e indicadores estables (> 30%).
* **Estado Cansado:** Ojos adormilados si la batería cae por debajo del 30%.
* **Estado Buggeado:** Ojos rojos de alerta si la salud cae por debajo del 30%.
